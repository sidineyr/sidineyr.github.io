# Privacidade — Quality View

Este repositório contém apenas uma jornada da Casa de Cursos. Nela, o caderno e o progresso ficam neste navegador, e a atividade oferece exportação do caderno como arquivo de texto. Isso não confirma como o app QV real armazena respostas nem se exporta CSV.

## Requisitos para o app QV
- Armazenamento local: **A validar no repositório do app**.
- Exportação CSV: **A validar no repositório do app**.
- Acesso do gestor: exclusivamente agregado; nunca expor respostas individuais.
- Mínimo de respondentes: não foi encontrada regra existente. O valor é **A medir no piloto** e requer aprovação antes de ser habilitado.
- Até haver limite aprovado, não exibir agregados. Se o grupo não cumprir o limite aprovado, apresentar exatamente: “Agregado indisponível - grupo pequeno”.

Não declarar coleta, armazenamento, exportação ou proteção no app sem verificar o código do produto. Não publicar dados individuais.
