# Como contribuir

Obrigado por ajudar a corrigir, explicar ou tornar estes projetos mais
acessíveis.

## Antes de propor uma mudança

- Consulte o README e a licença do projeto relacionado.
- Para relatar um erro, use o canal público de issues do GitHub. Inclua o
  endereço da página, o comportamento observado e uma fonte verificável quando
  a correção depender de um fato.
- Não publique senhas, dados de saúde, documentos, informações privadas ou
  respostas identificáveis de estudantes. Issues e pull requests são públicos.
- Para uma barreira de acessibilidade, informe navegador e forma de navegação,
  sem incluir dados pessoais.

## Pull requests

- Faça mudanças pequenas e explique o motivo.
- Preserve URLs públicas, métricas originais e opções de privacidade.
- Não introduza dados, credenciais, dependências ou afirmações biográficas sem
  autorização e evidência.
- Rode `python -X utf8 -m unittest discover -s tests -v` e
  `python -X utf8 scripts/generate-sitemap.py --check`.
- Descreva os testes e limitações no pull request. As verificações automatizadas
  não substituem teste manual de teclado, leitor de tela e reflow.
