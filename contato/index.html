Contato e correções

Atualizado em 18 de novembro de 2026.

Encontrou uma informação imprecisa, um link quebrado ou uma dificuldade para usar o site? O canal público de acompanhamento é o repositório do portfólio.

Abrir uma solicitação no GitHub · Consultar solicitações existentes

O GitHub pode pedir uma conta para publicar. A leitura do portfólio e das oficinas continua livre, sem cadastro.

O que incluir

  1. O endereço exato da página e o trecho ou controle que apresentou problema.
  2. O que você esperava e o que aconteceu. Para erros de conteúdo, indique uma fonte que permita conferir a correção.
  3. Se for uma barreira de acesso, informe o navegador e a forma de navegação, como teclado, leitor de tela ou celular.

Não publique senhas, códigos de verificação, dados de saúde, documentos ou respostas pessoais de estudantes. As solicitações no GitHub são públicas. Ao anexar uma imagem, remova dados que identifiquem terceiros.

Qual projeto apresentou o problema?

Para um erro nesta página, na Casa de Cursos ou na navegação do catálogo, use o repositório do portfólio. Se a dificuldade estiver em um aplicativo vinculado, consulte também o README e o canal de problemas do próprio projeto. Eles podem ter requisitos e políticas diferentes.

Como as correções são acompanhadas

O registro público permite discutir a evidência e acompanhar a alteração. A publicação de uma solicitação não garante prazo de resposta ou implementação de toda sugestão. Quando houver uma correção, os commits mostram os arquivos alterados e a justificativa. Para saber como o conteúdo é preparado, leia a política editorial.
