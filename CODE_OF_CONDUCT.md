# Código de conduta

Este projeto busca ser um espaço respeitoso para aprender, propor mudanças e
relatar problemas. Participe com cordialidade, critique ideias e decisões sem
atacar pessoas e considere experiências diferentes das suas.

Não são aceitos assédio, discriminação, ameaças, exposição de dados pessoais,
spam ou conteúdo sexual dirigido a menores. Não publique informações
identificáveis de estudantes.

Para relatar uma situação, use uma issue pública sem incluir dados sensíveis.
Se o relato exigir privacidade, consulte o canal disponível no perfil público
do autor; não presuma que issues aceitam mensagens privadas. O mantenedor pode
editar ou remover conteúdo que viole estas regras e limitar a participação
reincidente.

Este código adapta os princípios do Contributor Covenant, versão 2.1:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/
