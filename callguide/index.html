CallGuide

Prática de caligrafia no Android, com orientação e liberdade para aprender no seu ritmo.

Aplicativo gratuito e offline para exercícios introdutórios de escrita à mão. Reúne modelos de letras, atividades com palavras e uma área pautada para traçar com o toque.

Ver repositório no GitHub ↗Instruções para gerar e testar o APK ↗

Recursos para praticar

  • Orientações sobre postura, preensão do lápis, pressão e ritmo.
  • Exercícios progressivos com letras e palavras.
  • Área de traçado com controles para desfazer e limpar.
  • Interface em português compatível com leitores de tela.

Uso offline e privacidade

O aplicativo funciona localmente, sem cadastro, anúncios ou coleta de dados. Não solicita acesso à internet nem armazena os traçados concluídos.

Esta página apresenta o projeto; a prática de escrita acontece no aplicativo Android.

Legibilidade, conforto e autoria

O CallGuide incentiva a prática deliberada e respeita diferentes ritmos de aprendizagem e habilidades motoras. Não atribui notas nem define uma caligrafia “perfeita”.

Como testar no Android

O código-fonte está disponível sob licença MIT. Para gerar um APK de teste, siga o README do repositório: o projeto usa Android Studio, JDK 11 e Android SDK 33. No Windows, há um script para gerar o APK e, opcionalmente, instalá-lo em um dispositivo conectado por USB.
